# Cowart 画布

在 Claude Code 桌面版旁边开一块无限画布，把图片、视频、网页截图、AI 做的网页草稿都摊在上面看。想改哪张图，就在画布上画个箭头、写一句「这里换成夜景」，点 AI 按钮发出去，AI 照着改，新图自动放在原图旁边，前后一比就清楚。

适合用 Claude Code 桌面版做美术、策划、UI 的同事：要把一批图摊开比较、挑方向，要对着图给 AI 提修改意见，或者想让 AI 照某个网页做一版 HTML 原型。

## 能做什么

- **按标注改图 / 生图**：在图上画圈写批注，AI 按批注出新图放在旁边。默认用猛兽上免费的本地模型，要花钱的云端模型会先问你
- **AI 图片 / AI 视频**：在画布面板里选好模型和参数点发送，画布直接调猛兽生成、放回画布，不用经过对话
- **AI HTML / AI Slides**：在画布上拉一个框写需求，AI 写好网页或几页幻灯片放进框里
- **照网页做 HTML**：贴一个网址，AI 照着它的样子做一版
- **整理画布**：让 AI 给图编号、加标题、分组、排整齐、删掉不要的
- **分页干活**：全机一张画布、分很多页，每个会话管一页，几件事可以同时做

## 怎么开始

1. 在 Skillbook 书架上点开这本，把借阅语发给你的 AI，它会照安装说明装好。中间会问你要「省心版」（作者打包好的，推荐）还是「开发版」（源码，想自己改再选）。
2. 新开一个会话，说「打开 Cowart 画布」，画布就在右边的 Browser 面板里打开；说「接管 角色设定」就新建或接手「角色设定」这一页。

## 要先装什么

- **Claude Code 桌面版**（Windows / Mac，公司中转的桌面版也行）。命令行版 claude 用不了；电脑上装了 Codex 的，装的时候顺带让 Codex 也能用（画布在 Codex 的内置浏览器里看）。
- **Node 22.12 以上**。
- **猛兽的 beast 命令行**：出图靠它。过了猛兽新手关的同事已经有了；没有也能用画布，只是 AI 图片 / AI 视频要改成发给会话来做。
