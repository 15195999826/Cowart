# Cowart · Claude Code 适配层

让上游 Cowart 画布在 **Claude Code 桌面版**里可用。改动都在本目录和 `adapters/shared/`；上游只开了几个通用的扩展接口（工具栏加按钮、图片工具栏加按钮、接管 AI 图片面板），另外把标注改成绑定到卡片（补丁点见仓库根目录 [FORK.md](../../FORK.md)）。

## 它做了什么

```
Claude Code ──stdio MCP──▶ 适配层 cowart-claude-mcp.mjs ──stdio MCP──▶ 上游 Cowart 服务（mcp/generated，黑盒子进程）
                              │
                              ├─ 本地网页服务 127.0.0.1:43240 起 ──▶ Browser 面板里的画布页面
                              │     └─ 上游画布页面 + 注入的 Claude 宿主桥（web/bridge.js）+ 两边共用的页面脚本（../shared/web）
                              └─ 画布请求队列 ──▶ cowart-listen.mjs（Monitor 工具运行）──▶ 唤醒 Claude 会话
```

| 上游在 Codex 里的做法 | 这里的替代 |
|---|---|
| MCP Apps widget 内嵌显示 | 本地网页服务，在 Browser 面板打开 |
| 画布调工具走 MCP Apps 桥 | 注入 `window.cowartMcp`，经本地 HTTP 转发给上游服务 |
| 画布发消息 = `ui/message` 对话轮 | 进请求队列 → Monitor 通知 → Claude 用确认卡片问用户 → 执行 |
| Codex 内置 imagegen | AI 图片面板里选 beast-gen 模板；上游其它生图请求改用 beast-gen skill |
| GA4 统计 | 统计工具不转发，页面安全策略挡掉所有外部域名 |

另外补了上游没有的：

- **AI 图片面板按 beast-gen 能力选**：点 AI 图片框弹出的面板换成适配层的：参考图、描述，底栏选模型（自动 / Krea 2 / FLUX.2 Klein / FLUX.2 Dev / Ideogram 4 / Lib Image 2.5 Fast·Pro）和参数（画幅、清晰度、张数、档位、透明底），右侧显示大概耗时或「消耗团队额度」。画幅也在参数里选：选了框就变成那个比例并锁定，拖框角只改大小（上游原本放在右上角的「尺寸 / 比例」不再显示，控制项都在这一个面板里）。先选中图片再点 AI 图片，框会建在图片右边的空地上，这些图自动成为参考图。「自动」由 Claude 按需求挑模板，确认卡片里写明挑了哪个。
- **标注绑定到卡片**：用底部「标注」工具从任意位置拖一根箭头，拖动时鼠标下的卡片会高亮，在卡片上松手，箭头尖就钉在松手的那个点，接着写要求：回车完成（Shift+回车换行），也可以按 Esc 或点别处；完成后回到选择模式，点到的卡片会被选中、出现它的工具栏，再画一条要重新点「标注」。没写字就结束的标注直接撤掉，不会留下空箭头。能标的卡片是图片（含网页卡片）、视频、AI HTML、AI Slides；松手的地方不是卡片，这根箭头会撤掉并提示「标注要指向一张卡片」。绑定关系存在画布数据里：移动卡片时标注整条跟着走，删卡片时它的标注一起删（撤销时一起回来）；把箭头尖拖到另一张卡片上就改绑到松手的位置，拖到空白处（或整根箭头拖得箭头尖离开了卡片）会退回原位并提示。按标注修改 / 按标注生成 Html、AI HTML 和 AI Slides 的按标注修改、网页卡片的「照这个做 HTML」都只取绑在这张卡片上的标注（上游原本按卡片周围一圈里的红色箭头和文字去猜）；发给 AI 的请求除了截图，还逐条列出每个标注的字和它指向卡片上的位置。只认「标注」「注释」工具画的箭头，红色文字、普通箭头不算；以前画的标注，打开画布时箭头尖落在卡片上的会自动补上绑定。
- **标注和注释**：底部工具栏「标注」旁边有「注释」（图钉图标），用法一样，画出来是蓝色虚线。标注是一次性的修改要求（红色）；注释是常驻在卡片上的说明（比如「这是主角，别换脸」「品牌色 #FF5500」）。发给 AI 时标注列为「要改的地方」，注释单列为「背景参考，不是这次要改的」。需求做完后，选中卡片，工具栏里点「清理标注 (N)」删掉这张卡片上的标注，注释留下（Ctrl+Z 可以撤销；没有可清的标注时不显示这个按钮）。图片（含网页卡片）、视频、AI HTML、AI Slides 的工具栏都有这个按钮。
- **AI 图片 / AI 视频框像卡片一样操作**：框是 tldraw 的 frame，原本中间空心、还能装东西（拖进去就成了它的子元素，生成替换时会被一起删掉）。现在单击框里任何位置就选中、按住拖动就挪；双击 = 选中并把光标放进面板的描述框；在描述框里按 Esc 跳回画布，框仍选中，这时按 Delete 删除卡片。卡片不再装东西（拖进去、粘贴、在里面画都不会变成它的子元素）。框外空白处双击建文字照旧。
- **把画布上的图 / 视频用作素材**，都进面板顶部的槽位：
  - 先选中再点 AI 图片 / AI 视频（选中的媒体直接成为素材）；
  - 把画布上的图 / 视频拖到卡片上松手：拖动时卡片上会提示「松手加为参考图 / 设为首帧 / 设为尾帧」，满了或类型不对会标红；松手后原图弹回原位，卡片被选中；
  - 在描述框里敲「/」弹出画布素材选择器（离卡片近的在前，可打字筛选，↑↓ + 回车）；点空槽位也弹这个选择器，里面多一项「上传本地文件…」；也可以直接粘贴图片。
  - AI 视频的首尾帧按顺序填（先首帧后尾帧），在槽位里把首帧拖到尾帧上就互换；参考素材在槽位里拖动调整顺序。
- **描述里用「@」引用素材**：敲「@」列出已选的素材，选中后插入「@图1」「@视频1」「@首帧」这样的标记，显示成蓝色标签（找不到对应素材的标成橙色，发送时会拦下提醒）；光标在标签后按一次退格就整个删掉。删掉或调整素材顺序时，@图N / @视频N / @音频N 自动重排（引用被删素材的标记一并去掉）。发给 AI 的请求里写明每个标记对应哪个文件，AI 按模型写法改写（H3 用 <Picture N>，Seedance 用「图片N」，FLUX 用 image N）。
- **网页参考**：在画布上粘贴网址（或点底部工具栏「媒体」旁边的「网页」输入网址），适配层在后台用本机 Chrome（没有就试 Edge；`COWART_BROWSER_PATH` 可指定）打开网页，按 1440 宽截整页长图（先滚到底让懒加载内容出来，最长 16000px），连同浏览器渲染后的页面代码存进页面素材，截图作为卡片放上画布，卡片记着网址、标题、截图时间。截图期间原地先放一个「网页 · 截图中…」的框，框里转圈提示后台在处理，截完换成卡片（中途刷新页面的话，框里会提示没截完）。选中卡片，上方还是那一排图片工具栏，只是换成网页卡片的组合：下载、ALT、按标注修改、网站名（点了打开原网页）、「照这个做 HTML」。「照这个做 HTML」顶替了「按标注生成 Html」；替换、裁剪不出现，卡片也不能裁剪，保证截图和原网页一一对应。「照这个做 HTML」可以写一句补充要求（可不填），在卡片右边建一个同尺寸的 AI HTML 框并把请求发给 Claude，AI 看截图、读页面代码（Claude 还能用 Browser 面板打开原网址对照），做成单文件 HTML 替换这个框，方便横向对比；每点一次多一版。
  - **按标注改**：想改哪里，先用底部「标注」工具拖一根箭头指到卡片上要改的地方、写要求（见上面的「标注绑定到卡片」），再点「照这个做 HTML」，弹框里会显示「会带上卡片上的 N 处标注」。发给 AI 的请求里逐条写明要求、箭头尖指的页面坐标（按 1440 宽排版的像素），并附一张卡片局部截图（带着那条标注），AI 按标注改、没标到的地方照原网页做。
- **画布界面精简**：左上角菜单去掉「创建嵌入」（外部网站嵌入在本地页面安全策略下是空白，网页改用上面的截图卡片）和「上传媒体文件」（底部工具栏「媒体」按钮是同一个功能），Ctrl+I 不再打开嵌入对话框；右上角的样式面板（颜色、填充、线型、大小）只在用画笔 / 形状 / 文字 / 箭头等工具或选中这类图形时出现，平时不常驻。
- **AI 视频**：底部工具栏的「AI 视频」按钮，用法跟 AI 图片一样：点一下，画布上出现「AI 视频」框，下方弹出输入面板（首尾帧 / 参考素材、模型、画幅、时长、描述）；发送后生成的视频替换这个框。新框默认用本地免费的 MiniMax H3，每个模型各自记住上次的参数。先选中一张图片再点，框会建在图片右边，并自动把这张图当首帧（图生视频）。
- **视频播放**：视频文件经本地服务按需分段加载，在画布上静音循环自动播放。视频不进 tldraw 的编辑态，任何时候都能直接拖；双击切换播放 / 暂停；选中后下方出现控制条（播放、进度、时间、声音）。
- **画布摘要**：模型调 `get_cowart_canvas_state` 拿到的是紧凑摘要（图形、位置、素材本地路径），不是几 MB 的原始快照。
- **写入保护**：同一画布的写操作排队、Windows 上的临时文件改名冲突（EPERM）自动重试；刚插入的视频不会被画布的旧快照自动保存冲掉，被视频替换掉的 AI 视频框也不会被带回来（上游只保护图片）。
- **状态浮层**：画布顶部显示 Claude 是否在监听、每个请求的状态（排队 / 等确认 / 处理中 / 完成）。还没开始处理的请求（排队 / 等确认）旁边有「撤销」按钮，点错了可以撤回：请求标成「已撤销」，Claude 这边会收到「已在画布上撤销」的通知，之后也不能再执行它。

## 配置

一次性安装依赖（仓库根目录执行）：

```bash
npm install --prefix adapters
```

把适配层注册成某个项目的 `cowart` MCP 服务（在那个项目目录下执行）：

```bash
claude mcp add cowart -s local -- node C:/WebProjects/Cowart/adapters/claude/bin/cowart-claude-mcp.mjs
```

新开 Claude Code 会话后生效。环境变量 `COWART_CLAUDE_PORT` 可以改起始端口（默认 43240，被占用时往后顺延）。

## 使用

1. 对 Claude 说「打开 Cowart 画布」。Claude 调 `render_cowart_canvas_widget`，按返回的指引在 Browser 面板打开网址，并用 Monitor 启动画布请求监听。
2. 画布顶部显示「● Claude 已连接」后，就可以在画布里点 AI 按钮了：底部工具栏的 AI 图片 / AI HTML / AI Slides / AI 视频，以及选中图片后的按标注修改 / 按标注生图。
3. 每个请求都会在对话里弹一张确认卡片，点了才执行：AI 图片 / AI 视频在面板里已经选好模型，卡片只问执行 / 跳过；其它请求在卡片里选免费本地模型 / 云端模型。结果回到画布，状态显示在画布顶部。

画布数据存在 `<项目>/canvas/`，和 Codex 版格式一致，两边可以打开同一个画布。

## 开发与检查

```bash
npm --prefix adapters run test:claude       # 端到端冒烟测试（临时项目，不碰真实画布）
npm --prefix adapters run check:contract    # 同步上游后跑：适配层依赖的上游接口是否还在
node adapters/claude/scripts/dev-host.mjs --project <目录>   # 不经 Claude Code 手动联调
```

`dev-host.mjs` 会像 Claude Code 一样启动适配层、打开画布，并在 `127.0.0.1:43299` 提供控制端口：带请求头 `x-cowart-dev: 1` 发 `POST /call {"name": "...", "arguments": {...}}`，就能直接调适配层的任意工具。

## 已知限制

- **每条画布请求都要在对话里确认一次**：Monitor 推来的是后台通知，不算用户输入。确认卡片同时用来确认花费（面板没选模型的请求也在这里选）。
- **面板里的草稿不跨刷新**：已加的参考图、写了一半的描述存在页面内存里，刷新页面会清空；模型参数会记住。
- **会话结束，服务就停**：适配层跟着 Claude Code 会话走。画布页面会显示「Cowart 服务未连接」，重新说「打开 Cowart 画布」即可接上（令牌持久化在 `~/.cowart-claude/token`，已打开的页面能自动重连）。
- **视频要本地服务在线才看得到**：视频不像图片那样缓存在页面内存里，会话结束、服务停掉后，已打开的画布上视频会变成空框；重新打开画布即可恢复。
- **自动播放绕开了「减少动态效果」**：tldraw 遇到系统开了这个设置就不自动播放，看起来像静态图。适配层改为每段视频加载后自动静音循环播放一次。
- **同一画布别在两个会话里同时开**：两个适配层会各自写同一份文件。
- **外部网站嵌入用不了**：页面安全策略只放行本地内容，tldraw 自带的「嵌入」（YouTube、Figma、GitHub Gist 等）会是空白，所以菜单入口已去掉；要参考网页请用「网页参考」截图卡片。
- **长网页卡片放大看顶部时，工具栏会消失**：tldraw 的图片工具栏只在卡片中心在屏幕内时出现，「照这个做 HTML」也在这一排里；缩小一点让卡片中心回到屏幕里就有了。
- **网页截图要本机有 Chrome 或 Edge**：Edge 152 在部分 Windows 机器上无头模式一启动就退出，所以优先用 Chrome；需要登录才能看的页面截到的是未登录的样子。
