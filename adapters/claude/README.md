# Cowart · Claude Code 适配层

让上游 Cowart 画布在 **Claude Code 桌面版**里可用。改动都在本目录、`adapters/service/`（全机共用的画布服务）和 `adapters/shared/`；上游只开了几个通用的扩展接口（工具栏加按钮、图片工具栏加按钮、接管 AI 图片面板），另外把标注改成绑定到卡片（补丁点见仓库根目录 [FORK.md](../../FORK.md)）。

## 它做了什么

```
Claude Code 会话 A ──stdio MCP──▶ 薄桥 cowart-claude-mcp.mjs ──┐
Claude Code 会话 B ──stdio MCP──▶ 薄桥 cowart-claude-mcp.mjs ──┤ HTTP 127.0.0.1:43240（令牌）
                                                               ▼
                    画布服务 adapters/service（全机一个，后台进程，空闲 10 分钟退出）
                      ├─ 上游 Cowart 服务（mcp/generated，黑盒子进程，只有一个）
                      ├─ 网页画布 ──▶ 各会话 Browser 面板里的画布页面（网址带会话标识）
                      │     └─ 上游画布页面 + 注入的 Claude 宿主桥（web/bridge.js）+ 两边共用的页面脚本（../shared/web）
                      └─ 请求队列（按页路由）──▶ cowart-listen.mjs --session（各会话的 Monitor）──▶ 唤醒负责那一页的会话
```

| 上游在 Codex 里的做法 | 这里的替代 |
|---|---|
| MCP Apps widget 内嵌显示 | 画布服务在本地提供网页，在 Browser 面板打开 |
| 画布调工具走 MCP Apps 桥 | 注入 `window.cowartMcp`，经本地 HTTP 交给画布服务里的上游服务 |
| 画布发消息 = `ui/message` 对话轮 | 进请求队列 → 发给负责这一页的会话 → Monitor 通知 → Claude 用确认卡片问用户 → 执行 |
| Codex 内置 imagegen | AI 图片面板里选 beast-gen 模板；上游其它生图请求改用 beast-gen skill |
| GA4 统计 | 统计工具不转发，页面安全策略挡掉所有外部域名 |

另外补了上游没有的：

- **全机一个画布服务**：每个会话只跑一个很小的 MCP 桥，画布网页、上游子进程、请求队列都在同一个后台服务里：第一次用时自动在后台拉起，之后各会话复用；没有会话连着、也没有打开的画布页面，10 分钟后自动退出。同一张画布可以同时在几个会话里开着，写入都经这一个服务排队，不会再两边各写一份文件。
- **分页负责制**：一张画布大家共用，谁都能看、能改；权限只在「页」上（tldraw 的页，左上角切换）。每一页同一时间由一个会话负责，每个会话最多负责一页。在哪个会话里说「打开 Cowart 画布 角色设定」（或「接管 角色设定」「接管这页」），「角色设定」就归它：没有这页就新建，原来负责它的会话自动让出，这个会话之前负责的页放掉。只说「打开 Cowart 画布」只打开画布，不进任何页；在画布上翻页只是看。某一页的 AI 请求发给负责它的会话，不管是在哪个会话的 Browser 面板里点的；没人负责的页，点它的那个面板所属的会话就顺手负责了。不带 `pageId` 的插入放进这个会话负责的页，没负责页时放进它的面板正看着的页（没人负责的话）；别的会话负责的页不能往里放东西（例外：它之前从那页发出、还在做的请求，结果照样放回），Claude 会提示你说「接管 <页名>」。之后不带目录调用的 Cowart 工具，都作用在这个会话最后打开的那张画布上。
- **同一页几个面板同时改也不出错**：上游页面每次保存整张画布，两个面板同时改会互相覆盖。这里的页面保存只交「我改了什么」（改动 / 新增的记录和删掉的记录），画布服务合到磁盘副本再存：晚同步的面板冲不掉别人的东西，没见过的页和记录也删不掉，AI 插进来的结果不会丢。两个面板同时在一页画东西，各自的东西都在；只有同一时刻改同一条记录，后一个才盖掉前一个。
- **请求按页送到负责的会话**：画布网址和监听命令都带会话标识，一个 Browser 面板就属于打开它的那个会话（画布顶部显示它的名字，这就是「我是谁」）。在某一页点 AI 按钮，请求进画布服务的队列、发给负责这一页的会话；面板上的提示条会写明发给了谁（「#5 AI 图片 → 阿满 · 请到阿满的对话里点执行」），`get / reply / list` 只看得到路由到本会话的请求。会话结束后，它负责的页变成没人负责，它打开的面板顶部显示「小川 的会话已结束：回到 Claude Code 重新打开画布才能接上」（在这个面板里点别的会话负责的页照样能发过去），没处理的请求留着；同一个会话恢复后自动接上并补发这些请求。
- **AI 图片 / AI 视频点发送就生成**：面板里模型和参数都选好了，点「发送」后画布服务直接调猛兽生成，不经过 Claude 会话、也不用在对话里确认：先写提示词（后台跑一次不带工具的 `claude -p`，按 beast-gen skill 里这个模型的写法把你的描述改写好，参考图一起给它看），再上传素材、提交、等结果，生成完直接替换占位框（要透明底的先抠图）。画布顶部的请求条显示走到哪一步（写提示词 / 排队 / 生成中 / 放进画布），放进画布之前可以点「撤销」停下。本机没装 beast 命令行时退回老路：请求发给会话、在对话里确认。
- **AI 图片面板按 beast-gen 能力选**：点 AI 图片框弹出的面板换成适配层的：参考图、描述，底栏选模型（自动 / Krea 2 / FLUX.2 Klein / FLUX.2 Dev / Ideogram 4 / Lib Image 2.5 Fast·Pro）和参数（画幅、清晰度、张数、档位、透明底），右侧显示大概耗时或「消耗团队额度」。画幅也在参数里选：选了框就变成那个比例并锁定，拖框角只改大小（上游原本放在右上角的「尺寸 / 比例」不再显示，控制项都在这一个面板里）。先选中图片再点 AI 图片，框会建在图片右边的空地上，这些图自动成为参考图。「自动」按需求在免费模板里挑（写提示词时一起定）。
- **标注绑定到卡片**：用底部「标注」工具从任意位置拖一根箭头，拖动时鼠标下的卡片会高亮，在卡片上松手，箭头尖就钉在松手的那个点，接着写要求：回车完成（Shift+回车换行），也可以按 Esc 或点别处；完成后回到选择模式，点到的卡片会被选中、出现它的工具栏，再画一条要重新点「标注」。没写字就结束的标注直接撤掉，不会留下空箭头。能标的卡片是图片（含网页卡片）、视频、AI HTML、AI Slides；松手的地方不是卡片，这根箭头会撤掉并提示「标注要指向一张卡片」。绑定关系存在画布数据里：移动卡片时标注整条跟着走，删卡片时它的标注一起删（撤销时一起回来）；把箭头尖拖到另一张卡片上就改绑到松手的位置，拖到空白处（或整根箭头拖得箭头尖离开了卡片）会退回原位并提示。按标注修改 / 按标注生成 Html、AI HTML 和 AI Slides 的按标注修改、网页卡片的「照这个做 HTML」都只取绑在这张卡片上的标注（上游原本按卡片周围一圈里的红色箭头和文字去猜）；发给 AI 的请求除了截图，还逐条列出每个标注的字和它指向卡片上的位置。只认「标注」「注释」工具画的箭头，红色文字、普通箭头不算；以前画的标注，打开画布时箭头尖落在卡片上的会自动补上绑定。
- **标注和注释**：底部工具栏「标注」旁边有「注释」（图钉图标），用法一样，画出来是蓝色虚线。标注是一次性的修改要求（红色）；注释是常驻在卡片上的说明（比如「这是主角，别换脸」「品牌色 #FF5500」）。发给 AI 时标注列为「要改的地方」，注释单列为「背景参考，不是这次要改的」。需求做完后，选中卡片，工具栏里点「清理标注 (N)」删掉这张卡片上的标注，注释留下（Ctrl+Z 可以撤销；没有可清的标注时不显示这个按钮）。图片（含网页卡片）、视频、AI HTML、AI Slides 的工具栏都有这个按钮。
- **AI 图片 / AI 视频框像卡片一样操作**：框是 tldraw 的 frame，原本中间空心、还能装东西（拖进去就成了它的子元素，生成替换时会被一起删掉）。现在单击框里任何位置就选中、按住拖动就挪；双击 = 选中并把光标放进面板的描述框；在描述框里按 Esc 跳回画布，框仍选中，这时按 Delete 删除卡片。卡片不再装东西（拖进去、粘贴、在里面画都不会变成它的子元素）。框外空白处双击建文字照旧。
- **把画布上的图 / 视频用作素材**，都进面板顶部的槽位：
  - 先选中再点 AI 图片 / AI 视频（选中的媒体直接成为素材）；
  - 把画布上的图 / 视频拖到卡片上松手：拖动时卡片上会提示「松手加为参考图 / 设为首帧 / 设为尾帧」，满了或类型不对会标红；松手后原图弹回原位，卡片被选中；
  - 在描述框里敲「/」弹出画布素材选择器（离卡片近的在前，可打字筛选，↑↓ + 回车）；点空槽位也弹这个选择器，里面多一项「上传本地文件…」；也可以直接粘贴图片。
  - AI 视频的首尾帧按顺序填（先首帧后尾帧），在槽位里把首帧拖到尾帧上就互换；参考素材在槽位里拖动调整顺序。
- **描述里用「@」引用素材**：敲「@」列出已选的素材，选中后插入「@图1」「@视频1」「@首帧」这样的标记，显示成蓝色标签（找不到对应素材的标成橙色，发送时会拦下提醒）；光标在标签后按一次退格就整个删掉。删掉或调整素材顺序时，@图N / @视频N / @音频N 自动重排（引用被删素材的标记一并去掉）。发给 AI 的请求里写明每个标记对应哪个文件，AI 按模型写法改写（H3 用 <Picture N>，Seedance 用「图片N」，FLUX 用 image N）。
- **网页参考**：在画布上粘贴网址（或点底部工具栏「媒体」旁边的「网页」输入网址），画布服务在后台用本机 Chrome（没有就试 Edge；`COWART_BROWSER_PATH` 可指定）打开网页，按 1440 宽截整页长图（先滚到底让懒加载内容出来，最长 16000px），连同浏览器渲染后的页面代码存进页面素材，截图作为卡片放上画布，卡片记着网址、标题、截图时间。截图期间原地先放一个「网页 · 截图中…」的框，框里转圈提示后台在处理，截完换成卡片（中途刷新页面的话，框里会提示没截完）。选中卡片，上方还是那一排图片工具栏，只是换成网页卡片的组合：下载、ALT、按标注修改、网站名（点了打开原网页）、「照这个做 HTML」。「照这个做 HTML」顶替了「按标注生成 Html」；替换、裁剪不出现，卡片也不能裁剪，保证截图和原网页一一对应。「照这个做 HTML」可以写一句补充要求（可不填），在卡片右边建一个同尺寸的 AI HTML 框并把请求发给 Claude，AI 看截图、读页面代码（Claude 还能用 Browser 面板打开原网址对照），做成单文件 HTML 替换这个框，方便横向对比；每点一次多一版。
  - **按标注改**：想改哪里，先用底部「标注」工具拖一根箭头指到卡片上要改的地方、写要求（见上面的「标注绑定到卡片」），再点「照这个做 HTML」，弹框里会显示「会带上卡片上的 N 处标注」。发给 AI 的请求里逐条写明要求、箭头尖指的页面坐标（按 1440 宽排版的像素），并附一张卡片局部截图（带着那条标注），AI 按标注改、没标到的地方照原网页做。
- **画布界面精简**：左上角菜单去掉「创建嵌入」（外部网站嵌入在本地页面安全策略下是空白，网页改用上面的截图卡片）和「上传媒体文件」（底部工具栏「媒体」按钮是同一个功能），Ctrl+I 不再打开嵌入对话框；右上角的样式面板（颜色、填充、线型、大小）只在用画笔 / 形状 / 文字 / 箭头等工具或选中这类图形时出现，平时不常驻。
- **AI 视频**：底部工具栏的「AI 视频」按钮，用法跟 AI 图片一样：点一下，画布上出现「AI 视频」框，下方弹出输入面板（首尾帧 / 参考素材、模型、画幅、时长、描述）；发送后生成的视频替换这个框。新框默认用本地免费的 MiniMax H3，每个模型各自记住上次的参数。先选中一张图片再点，框会建在图片右边，并自动把这张图当首帧（图生视频）。
- **视频播放**：视频文件经本地服务按需分段加载，在画布上静音循环自动播放。视频不进 tldraw 的编辑态，任何时候都能直接拖；双击切换播放 / 暂停；选中后下方出现控制条（播放、进度、时间、声音）。
- **画布摘要**：模型调 `get_cowart_canvas_state` 拿到的是紧凑摘要（图形、位置、素材本地路径），不是几 MB 的原始快照。
- **写入保护**：同一画布的写操作在画布服务里排队，Windows 上的临时文件改名冲突（EPERM）自动重试；刚插入的视频不会被画布的旧快照自动保存冲掉，被视频替换掉的 AI 视频框也不会被带回来（上游只保护图片）。
- **状态浮层**：画布顶部第一行是这个面板所属会话的状态：「小川 · 负责「角色设定」 · Claude 已连接」（还有：没负责任何页 / 未在监听 · 请求会排队 / 会话已结束 / 画布服务在重启）；这一页不归这个会话时多一行「这一页由阿满负责 [换成小川]」或「这一页还没人负责 [小川来负责]」，点按钮就换人。下面是每个请求的状态（排队 / 等确认 / 处理中 / 完成；直接生成的显示当前步骤），发给别的会话的请求会标出会话名。还没开始处理的请求（排队 / 等确认）旁边有「撤销」按钮，点错了可以撤回：请求标成「已撤销」，Claude 这边会收到「已在画布上撤销」的通知，之后也不能再执行它。

## 配置

一次性安装依赖（仓库根目录执行）：

```bash
npm install --prefix adapters
```

把适配层注册成某个项目的 `cowart` MCP 服务（在那个项目目录下执行）：

```bash
claude mcp add cowart -s local -- node C:/WebProjects/Cowart/adapters/claude/bin/cowart-claude-mcp.mjs
```

新开 Claude Code 会话后生效。工具只在桌面版提供：会话入口（`CLAUDE_CODE_ENTRYPOINT`）不是 `claude-desktop` 时（命令行版、VS Code 插件等），cowart 不提供工具、也不拉起画布服务。

环境变量：

- `COWART_CLAUDE_PORT`：画布服务的端口，默认 43240；被别的程序占着就往后找。
- `COWART_CANVAS_DIR`：全机那张画布放在哪，默认 `~/.cowart/canvas`；只管会话拉起的那个服务，平时不用设。
- `COWART_ALLOW_CLI=1`：命令行版等非桌面入口也提供工具（没有 Browser 面板，网址在浏览器里打开）。
- `COWART_SERVICE_IDLE_MS`：画布服务空闲多久退出，默认 10 分钟。
- `COWART_BEAST_CLI`：猛兽命令行的位置，默认 `~/.beast/bin/beast.mjs`；找不到时 AI 图片 / AI 视频退回发给会话。
- `COWART_PROMPT_WRITER=off`：画布直接生成时不改写提示词，按原话（套上模板必需的结构）生成；`COWART_PROMPT_MODEL` 换写提示词的模型（默认 haiku），`COWART_CLAUDE_CLI` 指定 claude 可执行文件。

画布服务不用手动管，需要时看一眼或停掉：

```bash
npm --prefix adapters run service:status    # 在跑的服务、连着的会话和页面
npm --prefix adapters run service:stop      # 停掉它，下次有会话要用时自动拉起
```

服务日志在 `~/.cowart-claude/service.log`。

## 使用

1. 对 Claude 说「打开 Cowart 画布」，或「打开 Cowart 画布 角色设定」让这个会话负责「角色设定」这一页（没有就新建）。Claude 调 `render_cowart_canvas_widget`，按返回的指引在 Browser 面板打开网址，并用 Monitor 启动这个会话的画布请求监听。
2. 画布顶部显示「● Claude 已连接」后，就可以在画布里点 AI 按钮了：底部工具栏的 AI 图片 / AI HTML / AI Slides / AI 视频，以及选中图片后的按标注修改 / 按标注生图。
3. AI 图片 / AI 视频点「发送」就开始生成，进度和结果都在画布上。其它请求（按标注修改、AI HTML、AI Slides、照这个做 HTML）在负责这一页的会话里弹一张确认卡片，点了才执行，卡片里选免费本地模型 / 云端模型。结果回到画布，状态显示在画布顶部。

画布是画布服务的，全机只有一张，所有会话、所有项目都在上面按页分工：数据存在 `~/.cowart/canvas/`（每页一个目录，素材跟着页走），格式和 Codex 版一致。以前存在各项目 `canvas/` 下的页，用 `node adapters/service/bin/cowart-service.mjs --import <画布目录> …` 搬进来（整页目录拷过去，原目录不动）。

## 开发与检查

```bash
npm --prefix adapters run test:claude       # 端到端：冒烟测试 + 多会话测试（临时项目、测试端口，不碰真实画布）
npm --prefix adapters run test:multi        # 只跑多会话测试
npm --prefix adapters run check:contract    # 同步上游后跑：适配层依赖的上游接口是否还在
node adapters/claude/scripts/dev-host.mjs --project <目录> [--session <标识>] [--canvas <目录>]   # 不经 Claude Code 手动联调
```

`dev-host.mjs` 会像 Claude Code 一样启动一个会话桥、打开画布，并在 `127.0.0.1:43299` 提供控制端口：带请求头 `x-cowart-dev: 1` 发 `POST /call {"name": "...", "arguments": {...}}`，就能直接调任意工具。它用自己的会话标识（默认 `dev-host`），不会动你当前会话负责的页；设 `COWART_CLAUDE_PORT` 换个端口、再用 `--canvas` 给一个临时画布目录，就是一套独立的测试服务（不换端口时 `--canvas` 不让用，免得机器上的画布服务换了画布）。

改了画布服务会加载的代码（`adapters/service`、`adapters/shared/*.mjs`、上游产物）后，新开的会话发现代码指纹变了，会让旧服务退出、拉起新服务，已打开的页面自动重连。从别的代码目录来的桥（比如 Codex 的插件缓存）只在版本号更大时才替换，不会两边来回抢。页面脚本（`web/`、`../shared/web/`）每次打开页面都现读，刷新页面就生效；桥的改动新开会话生效。

## 已知限制

- **按标注修改、AI HTML 这类请求要在对话里确认一次**：它们要会话里的 Claude 动手，而 Monitor 推来的是后台通知、不算用户输入，所以每条都先问（卡片同时用来选免费 / 云端模型）。AI 图片 / AI 视频不经过会话，点发送就生成。
- **直接生成的提示词靠后台的 `claude -p` 写**：要本机能跑 `claude`（用的是本机 Claude Code 的登录额度，haiku 每次约 5 秒）；跑不了时按原话生成，H3 视频和 Ideogram 的效果会差一截（它们要英文结构化提示词 / JSON 标注）。
- **面板里的草稿不跨刷新**：已加的参考图、写了一半的描述存在页面内存里，刷新页面会清空；模型参数会记住。
- **会话结束后页面要重新打开**：会话结束，它打开的页面显示「会话已结束」，它负责的页变成没人负责。同一个会话恢复后会自动接上；在别的会话里用，要在那个会话里说「打开 Cowart 画布」拿新网址（网址里带会话标识）。
- **画布服务重启会丢请求队列**：请求只存在画布服务的内存里，服务被新版本替换或被停掉后，没处理完的请求就没了；正在直接生成的也会断（猛兽上的任务照样跑完，结果不会放进画布）。
- **同一时刻改同一条记录，后保存的覆盖**：页面保存只交差异，两个面板改不同的东西互不干扰；但同一条记录（同一张卡片的位置、同一段文字）在 1.6 秒的同步间隔里被两个面板同时改，后保存的那份覆盖先保存的。
- **视频要画布服务在线才看得到**：视频不像图片那样缓存在页面内存里，服务不在时（比如手动停掉），已打开的画布上视频会变成空框；重新打开画布即可恢复。
- **自动播放绕开了「减少动态效果」**：tldraw 遇到系统开了这个设置就不自动播放，看起来像静态图。适配层改为每段视频加载后自动静音循环播放一次。
- **只在桌面版提供**：命令行版、VS Code 插件里 cowart 没有工具（设 `COWART_ALLOW_CLI=1` 可放开）。
- **外部网站嵌入用不了**：页面安全策略只放行本地内容，tldraw 自带的「嵌入」（YouTube、Figma、GitHub Gist 等）会是空白，所以菜单入口已去掉；要参考网页请用「网页参考」截图卡片。
- **长网页卡片放大看顶部时，工具栏会消失**：tldraw 的图片工具栏只在卡片中心在屏幕内时出现，「照这个做 HTML」也在这一排里；缩小一点让卡片中心回到屏幕里就有了。
- **网页截图要本机有 Chrome 或 Edge**：Edge 152 在部分 Windows 机器上无头模式一启动就退出，所以优先用 Chrome；需要登录才能看的页面截到的是未登录的样子。
